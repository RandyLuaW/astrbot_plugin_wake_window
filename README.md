# 群聊接话窗口：被 @ 一次之后，接下来几句不用再 @

> AstrBot 插件 · 被 @ 一次之后，接下来几句不用再 @

## 它解决什么问题

唤醒判定是**逐条**的：每条群消息都要 @ 或唤醒前缀，否则直接 `stop_event()`。所以真实体验是：

你 @ 它 → 它回一句 → 你接着说「那你说说看」→ 没人理。对话断了。

而人不是这样聊天的。被叫到之后，接下来的几句话默认还在跟它说。

## 功能

- 记住每个群最近一次被接住的时间，窗口内放行普通消息
- 每放行一条就**续窗**，对话持续时窗口不断
- 窗口外照旧拦掉，与框架默认行为一致
- @ 了别人（不是它）时不插嘴
- 命令（唤醒前缀开头）走原路放行
- `merge_previous_seconds`：先发图再 @ 它时，往回并入前面的消息
- 按群独立，可用 `groups` 限定生效范围

## 工作机制

被 @ → 开窗（window_seconds）
窗口内普通消息 → 放行 + 续窗
窗口外 → 拦掉
@ 别人 → 拦掉
命令 → 放行

同一群两次主动唤醒至少间隔 wake_cooldown_seconds，
否则窗口内每句话都会触发一次完整回复。

## 安装

### 方式一：插件市场（推荐）

WebUI 插件市场搜索「群聊接话窗口」。

### 方式二：Releases 下载

从 [Releases](../../releases) 下载 zip，WebUI → 插件 → 上传安装。

### 方式三：手动克隆

```bash
cd AstrBot/data/plugins
git clone https://github.com/RandyLuaW/astrbot_plugin_wake_window.git
```

无额外 Python 依赖。

## 配置项

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 启用。关掉后群聊恢复成每条都要 @ 才能唤醒。 |
| `window_seconds` | int | `120` | 被 @ 之后多少秒内继续接话。每放行一条会续窗，对话持续时窗口不断。 |
| `wake_cooldown_seconds` | int | `90` | 同一个群两次主动唤醒的最小间隔。窗口内每句话都会唤醒她，不加冷却就变成逐条回复。 |
| `merge_previous_seconds` | int | `90` | 先发图、再 @ 她时，往回找多久以内的消息并进来。 |
| `merge_max_messages` | int | `3` | 最多并进来几条前面的消息。 |
| `groups` | list | `[]` | 只在这些群生效（填群号）。留空 = 所有群。 |
| `log` | bool | `false` | 打日志看开窗/续窗（排查用，平时关掉）。 |

## 注意事项

- `wake_prefix` 读的是**全局配置**（`cmd_config.json`），不是插件配置
- 冷却时间太短会让它逐条回复，太长对话又会断，90 秒是折中
